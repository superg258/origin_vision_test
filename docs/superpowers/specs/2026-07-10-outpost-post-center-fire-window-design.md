# 前哨站非对称开火窗口设计

## 目标

只调整老车前哨站模式，不影响普通自瞄、全向感知切换和打符。前哨装甲板到达中心前允许提前 3 度开火，经过中心后继续允许到 45 度，以增加单块装甲板经过时的弹量。

视觉端只发送逐帧的开火布尔值，没有弹丸计数反馈。因此“约 5 发”通过延长允许开火时间近似实现，实际发数仍取决于电控拨弹频率。

## 相位定义

用目标角速度方向归一化瞄准装甲板相位：

```text
moving_phase = limit_rad(aim_armor_yaw - target_center_yaw) * sign(target_yaw_speed)
```

- `moving_phase < 0`：装甲板正在接近中心。
- `moving_phase = 0`：装甲板位于中心。
- `moving_phase > 0`：装甲板已经经过中心。

正转和反转使用同一个窗口判断。

## 行为

前哨站只有同时满足以下条件时才允许开火：

1. tracker 处于 tracking。
2. 前哨层级已锁定。
3. 瞄准点有效。
4. `moving_phase` 位于 `[-3°, 45°]`。
5. 原有云台误差和命令连续性检查通过。

前哨选板的离开侧保持角同步改为 45 度，避免开火窗口尚未结束时提前切换到下一块装甲板。接近侧选板范围保持 70 度。

## 配置

复用并真正接入以下前哨专用参数：

```yaml
outpost_aim_coming_angle: 70
outpost_aim_leaving_angle: 45
outpost_fire_coming_angle: 3
outpost_fire_leaving_angle: 45
```

- `outpost_fire_coming_angle`：中心前允许开火的角度，调小可减少提前开火。
- `outpost_fire_leaving_angle`：中心后允许开火的角度，调大可增加弹量。
- `outpost_aim_leaving_angle`：同一装甲板经过中心后继续保持瞄准的角度，应不小于开火离开角。

普通目标继续使用现有 `comming_angle`、`leaving_angle` 和射击容差，不读取上述前哨参数。

## 安全与失败处理

- 未锁层、目标无效或 tracker 非 tracking 时立即停止开火。
- 相位超出窗口时立即停止开火，不增加无条件定时连发。
- 保留原有云台误差检查，避免仅因处于角度窗口内就开火。
- 参数缺失时使用设计默认值：接近 3 度、离开 45 度。

## 验证

自动测试覆盖：

- 正转时 `-3°` 到 `45°` 允许，窗口外拒绝。
- 反转时物理方向镜像后得到相同行为。
- 未锁层时拒绝开火。
- 普通目标的开火结果不受前哨参数影响。
- 前哨选板在离开侧 45 度以内保持当前装甲板。

上车先关闭供弹观察 `outpost_fire_moving_phase_deg` 与 `mpc_fire`，确认中心前约 3 度开始、中心后约 45 度结束，再开启供弹统计单块装甲板的实际弹数。
